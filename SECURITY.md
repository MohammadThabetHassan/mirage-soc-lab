# Security Policy

## Intended Use

MIRAGE is an educational, defensive simulation platform. Use only synthetic telemetry, owned lab systems, or systems for which you have explicit written authorization. Do not use this project to scan, exploit, test credentials, or collect data from systems you do not own or administer.

## Reporting a Vulnerability

Do not publish suspected vulnerabilities in public issues. Contact the repository owner privately with a minimal reproduction, affected component, impact assessment, and proposed mitigation. Do not include secrets, personal data, or active exploit payloads.
