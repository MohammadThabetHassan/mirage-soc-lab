# MIRAGE Visual Assets

This directory contains curated repository-presentation assets. The images are illustrative concepts only; they do not depict a deployed facility, a live SOC, customer data, or third-party telemetry.

| File                        | Intended use                                   | Repository handling                                                                                                  |
| --------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `mirage-soc-interior.webp`  | The single visual embedded in the root README. | Keep the alt text and controlled-lab disclaimer when changing its use.                                               |
| `mirage-social-preview.jpg` | GitHub repository social-preview upload.       | **Do not embed this image in the README.** Upload it through **Settings → Social preview → Edit → Upload an image**. |

The social-preview JPEG is 1280×640 and under 1 MB, matching GitHub’s recommended display size and upload constraints. See the [Public Release Checklist](../PUBLIC_RELEASE_CHECKLIST.md) for the public-visibility activation sequence.
